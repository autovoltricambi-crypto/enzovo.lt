## Google Ads Copy

### Struttura RSA (Responsive Search Ads)

**15 Titoli (max 30 char ciascuno) — strategia:**

```
Titoli con keyword (per rilevanza):
1. {KeyWord:Filtro Olio BMW} — DKI
2. Filtro Olio BMW N47
3. Ricambi BMW Online

Titoli con benefici:
4. Spedizione in 24 Ore
5. Compatibilità Garantita
6. Prezzi Competitivi
7. Reso Gratuito 30 Giorni
8. Ricambi OES Certificati

Titoli con urgenza/offerta:
9. Offerta Limitata
10. Acquista Online Ora
11. Risparmia sul Tagliando

Titoli con prova sociale:
12. 1.000+ Clienti Soddisfatti
13. Spedizioni Sicure e Veloci
14. Assistenza Tecnica Inclusa
15. Pagamenti 100% Sicuri
```

**4 Descrizioni (max 90 char):**
```
1. "Ricambi auto originali e aftermarket per BMW, Fiat, VW. Verifica compatibilità con la tua targa."
2. "Filtri, pastiglie, kit tagliando con spedizione rapida. Ordina entro le 14:00, ricevi domani."
3. "Compatibilità garantita o rimborso. Ricambi Elring, Bosch, Mann. Reso facile in 30 giorni."
4. "enzovo.lt — il tuo ricambista online. Assistenza tecnica gratuita per trovare il ricambio giusto."
```

### Regole Copy Google Ads

**Capitalizzazione:** Ogni Prima Lettera Maiuscola (aumenta CTR)

**Non ammesso:**
- Punteggiatura eccessiva (!!!, ???)
- Caratteri speciali
- Tutti i caratteri maiuscoli
- Affermazioni false o non verificabili

**Consentito ma usare con giudizio:**
- Prezzi specifici (si possono usare)
- Percentuali di sconto
- Emoji (rare, alcune funzionano)

### Display Ads Copy

### Formula Copy Meta per E-commerce

**Hook (prima riga — ferma lo scroll):**
```
Domanda: "Stai ancora pagando il concessionario per i ricambi BMW?"
Dichiarazione bold: "I ricambi BMW costano 3x di più dal concessionario"
Problema: "Il problema con i filtri BMW economici che trovate ovunque..."
Notizia: "Nuovo: kit tagliando N47 completo ora disponibile"
```

**Body (sviluppa il copy):**
- Max 3-5 righe visibili prima del "Leggi altro"
- Le prime 3 righe devono convincere a cliccare "Leggi altro"
- Usa bullet ✅/✓/• per leggibilità
- Emoji moderate (1-2 per paragrafo max)

**CTA nell'ad copy (diverso dal bottone CTA):**
```
"👇 Clicca per verificare la compatibilità con la tua auto"
"Scopri tutti i ricambi per BMW → [Link]"
"Aggiungi al carrello prima che finisca lo stock"
```

### Copy per Carousel Facebook

**Card 1:** Hook + problema principale
**Card 2-4:** Prodotti specifici con beneficio
**Card 5:** Offerta generale + CTA forte

```
Card 1: "Tagliando BMW? Risparmia il 60%"
Card 2: Filtro Olio N47 — €12.50 ✓ Compatibile
Card 3: Filtro Aria N47 — €14.90 ✓ Spedito Domani
Card 4: Kit Completo — €49.90 invece di €59.20
Card 5: "Acquista ora su enzovo.lt — Spedizione gratis sopra €35"
```

### Copy per Stories/Reels (Verticale)

**Durata:** 15 secondi → ogni secondo conta.

```
0-2s: Hook visivo + testo "Stai pagando troppo per..."
3-8s: Prodotto in primo piano + prezzo + beneficio
9-13s: Prova sociale (recensione) + garanzia
14-15s: CTA "Scopri ora → enzovo.lt"
```

## Copy per E-mail Marketing

### Oggetto Email

**Formule che funzionano:**
```
Urgenza: "Ultime 4 ore: filtro BMW a -20%"
Personalizzazione: "[Nome], ricambi per la tua BMW"
Curiosità: "Il modo giusto (e economico) di fare il tagliando BMW"
Re: (finge risposta): "Re: il tuo filtro olio"
Numero: "5 ricambi BMW che dovresti sempre avere in casa"
```

**Regole oggetto:**
- Max 50 caratteri (visualizzati su mobile)
- Evita spam words: GRATIS, OFFERTA, SCONTO, URGENTE, €€€
- Test A/B sempre (10-20% lista per versione, poi invia winner)

### Testo Email

**Apertura forte:**
```
"Ciao [Nome],

La tua BMW ha bisogno di attenzione — e noi abbiamo quello che serve."
```

**Struttura scannable:**
- Paragrafi di max 3 righe
- Bullet per liste
- **Bold** per punti chiave
- Un solo argomento principale per email

**CTA:**
```
Un solo bottone principale (non 5 link diversi)
Testo specifico: "Acquista il filtro olio per la tua BMW"
Non: "Clicca qui" o "Scopri di più"
```

## Copy Pagine Prodotto

**Titolo prodotto:**
```
[Marca] [Tipo] [Auto] [Modello] [Motore] — [Codice]
"Filtro Olio Elring BMW Serie 3 2.0d N47 — 163.810"
```

**Descrizione breve (per Google Shopping e anteprime):**
```
Max 160 caratteri, beneficio principale + compatibilità:
"Filtro olio OES Elring per BMW N47. Compatibile Serie 3 E90, Serie 5 E60.
Codice OE 11427566327. Spedizione 24h."
```

**Descrizione lunga:**
```
Paragrafo 1: Cos'è e a chi serve (keyword + beneficio)
Paragrafo 2: Specifiche tecniche (tabella)
Paragrafo 3: Compatibilità veicoli
Paragrafo 4: Perché scegliere questo prodotto
Paragrafo 5: Note di installazione
```

## Checklist Copy Ads

- [ ] Headline che ferma lo scroll (hook)
- [ ] Beneficio principale nei primi 3 secondi
- [ ] Prova sociale (numero clienti, recensioni)
- [ ] CTA specifica (non generica)
- [ ] Urgency/scarcity (se reale)
- [ ] Nessun errore grammaticale
- [ ] Formattato per mobile (righe corte, emoji moderate)
- [ ] A/B test pianificato su almeno 2 varianti
- [ ] Copy allineato con landing page (messaggio coerente)
