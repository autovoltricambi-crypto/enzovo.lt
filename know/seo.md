# Expertise: SEO per E-commerce Ricambi Auto (Italia)

## Logica SEO per Ricambi

Il cliente cerca sempre per **veicolo + parte**, non solo per parte.
Query tipiche:
- "filtro olio BMW Serie 3 2.0 diesel"
- "pastiglie freno Fiat Punto anteriori"
- "kit frizione Volkswagen Golf 1.9 TDI"
- "guarnizione testata Opel Astra 1.7 CDTI"

**Struttura URL ideale:**
```
/ricambi/[categoria]/[marca-auto]/[modello]/[parte]
/ricambi/filtri-olio/bmw/serie-3/filtro-olio-bmw-n47
```

## Keyword Strategy

### Long-tail ad alto intento (priorità massima)
Formato: `[parte] [marca] [modello] [motore/anno]`
- "filtro olio bmw n47 2.0d"
- "kit frizione valeo golf 1.9 tdi"
- "guarnizione testata elring bmw n47"

### Keyword da codice OE (conversioni altissime)
Chi cerca un codice OE SA già cosa vuole:
- "11427566327" → mostra la pagina prodotto direttamente
- Aggiungi il codice OE nel titolo e nella meta description

### Keyword informazionali (traffico alto, conversione bassa)
- "come cambiare filtro olio bmw"
- "sintomi guarnizione testata rotta"
- Utili per blog/guide che poi linkano ai prodotti

## Ottimizzazione Pagine Prodotto WooCommerce

### Titolo prodotto (H1)
```
[Marca Ricambio] [Codice] - [Nome Parte] [Marca Auto] [Modello] [Motore]
Elring 163.810 - Filtro Olio BMW Serie 3 2.0d N47 (2007-2013)
```

### Meta Description (160 caratteri)
```
Filtro olio originale Elring per BMW Serie 3 2.0d motore N47.
Codice OE: 11427566327. Spedizione rapida, prezzo competitivo. ✓ Compatibile 2007-2013
```

### Descrizione prodotto (per SEO)
Includere sempre:
1. Nome parte completo
2. Marca e modello auto compatibili
3. Codice OE di riferimento
4. Anno di produzione
5. Note di montaggio / compatibilità
6. Marche equivalenti (cross-reference)

### Schema Markup (Product)
WooCommerce genera automaticamente il Product schema — verifica che includa:
- `name`, `sku`, `price`, `availability`
- `brand` (marca ricambio)
- Aggiungi `vehicleEngine` se possibile

## Link Building e Autorità

- Registrarsi su **Subito.it** e **eBay** (genera backlink e visibilità)
- Profilo **Google My Business** aggiornato
- Pagine **come si cambia [parte] su [auto]** → traffico informazionale → link interni ai prodotti
- Forum auto italiani (Autopareri, MotorBox) → menzione naturale

## Velocità e Technical SEO

- Immagini prodotto ottimizzate: WebP, < 100KB, alt tag con keyword
- Cache plugin (WP Rocket o LiteSpeed Cache)
- Core Web Vitals: LCP < 2.5s, CLS < 0.1
- Sitemap XML aggiornata automaticamente (Yoast SEO)
- Canonical URL per varianti prodotto
