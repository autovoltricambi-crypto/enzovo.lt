# Copywriting — Fondamenti

## Cos'è il Copywriting

Il copywriting è l'arte di scrivere testi persuasivi che portano il lettore a compiere un'azione: acquistare, iscriversi, cliccare, condividere.

**Differenza:**
- **Content writing:** informa, educa, intrattiene
- **Copywriting:** persuade, converte

Ogni parola sul sito, nelle email, negli annunci ha un impatto sulle conversioni. Il copy è spesso la leva di marketing più sottovalutata.

## I Fondamentali della Persuasione

### 1. Parla dei Benefici, Non delle Caratteristiche

```
CARATTERISTICA: "Filtro olio con filtrazione a 3 stadi"
BENEFICIO: "Il tuo motore BMW dura il doppio grazie alla filtrazione avanzata"

CARATTERISTICA: "Spedizione in 24h"
BENEFICIO: "La tua auto è pronta domani"

CARATTERISTICA: "Garanzia 2 anni"
BENEFICIO: "Compra senza rischi — se qualcosa va storto, ci pensiamo noi"
```

**Regola:** per ogni caratteristica, chiedi "E quindi? Cosa significa per il cliente?"

### 2. Voce del Cliente (Voice of Customer — VoC)

Il copy più efficace usa le stesse parole del cliente. Come trovarle:
- Recensioni su Amazon/Trustpilot (tuo e dei competitor)
- Commenti Facebook/forum auto
- Email e chat con i clienti
- Sondaggi post-acquisto

```
Cliente reale: "Finalmente un sito dove posso trovare ricambi BMW senza
andare dal concessionario a pagare tre volte tanto"

→ Copy: "Ricambi BMW qualità originale. Senza prezzi da concessionario."
```

### 3. Specifico > Generico

```
GENERICO: "Spedizione veloce"
SPECIFICO: "Ordina entro le 14:00 → ricevi domani"

GENERICO: "Ottima qualità"
SPECIFICO: "Ricambi Elring, OES certificato per BMW"

GENERICO: "Buone recensioni"
SPECIFICO: "4.8/5 stelle da 1.247 clienti verificati"
```

### 4. La Regola WIIFM

**"What's in it for me?"** — il cliente pensa sempre a se stesso.

Ogni frase deve rispondere implicitamente: "Perché dovrebbe interessarmi?"

```
NON: "Siamo un'azienda fondata nel 2024 con passione per le auto"
SÌ: "Trova il ricambio giusto per la tua auto in 30 secondi"
```

## Framework Copywriting

### AIDA

**Attenzione → Interesse → Desiderio → Azione**

```
A: "La tua BMW perde più olio del previsto?"
I: "Il filtro olio originale si deteriora dopo 10.000 km. Sostituirlo ora
    evita danni al motore da migliaia di euro."
D: "Elring 163.810 — lo stesso filtro usato in fabbrica BMW.
    ✓ Compatibile N47 ✓ Spedito domani ✓ Reso gratuito"
A: "Aggiungi al carrello — €12.50"
```

### PAS

**Problema → Agitazione → Soluzione**

```
P: "Cercare ricambi BMW compatibili è un incubo"
A: "Sbagliare codice significa perdere tempo e soldi.
    Ricambi sbagliati che tornano indietro, ordini duplicati,
    attese infinite."
S: "enzovo.lt verifica la compatibilità per te.
    Inserisci targa → vedi solo i ricambi compatibili con la tua auto."
```

### FAB

**Feature → Advantage → Benefit**

```
F: Filtro olio con fibra di vetro sintetica
A: Filtra particelle fino a 15 micron (vs 25 micron del filtro standard)
B: Il tuo motore si usura meno → risparmia €1.200 sulla revisione futura
```

### Before/After/Bridge

```
Before: "Ogni anno paghi il concessionario per un tagliando da €200"
After: "Con enzovo.lt fai il tagliando da solo spendendo €35 in ricambi"
Bridge: "Scopri il kit tagliando per la tua auto"
```

## Psicologia del Copy

### Urgency
```
"Ordina entro le 14:00 → ricevi domani"
"Solo 2 rimasti in magazzino"
"Prezzo valido fino a domenica sera"
```
**Regola:** l'urgenza deve essere vera. Urgenza falsa = perdita di fiducia.

### Scarcity
```
"Ultimo pezzo disponibile"
"Stock limitato — fornitore in esaurimento"
```

### Social Proof
```
"1.247 clienti hanno acquistato questo filtro"
"Marco da Milano: 'Compatibilità perfetta, arrivato in 24h'"
"Il più venduto nella categoria Filtri BMW"
```

### Autorità
```
"Ricambi certificati OES per BMW"
"Fornitore ufficiale Elring, Mann, Corteco"
"Tecnico specializzato BMW risponde alle tue domande"
```

### Reciprocità
Dai valore prima di chiedere:
```
"Guida gratuita: come scegliere il filtro olio giusto per la tua BMW"
→ Download gratuito
→ Email di ringraziamento
→ Offerta prodotto correlato
```

### Garanzia (Riduzione del Rischio)
```
"30 giorni per cambiare idea — reso gratuito, nessuna domanda"
"Compatibilità garantita o rimborso immediato"
"Pagamento sicuro con carta — mai addebitato se non soddisfatto"
```

## Headline — La Parte Più Importante

L'headline (titolo) determina se il resto viene letto. L'80% degli utenti legge solo il titolo.

**Formule headline efficaci:**
```
Curiosità: "Il segreto dei meccanici BMW per motori longevi"
Numero: "5 ricambi che ogni BMW owner dovrebbe tenere in casa"
Come: "Come risparmiare €200/anno sul tagliando BMW"
Domanda: "Stai usando il filtro olio sbagliato per il tuo N47?"
Problema: "Filtri BMW originali finiti? Ecco il tuo migliore alternativo"
Beneficio diretto: "Ricambi BMW compatibili → consegnati domani"
```

## Errori Comuni da Evitare

| Errore | Esempio sbagliato | Corretto |
|--------|------------------|----------|
| Troppi aggettivi | "Fantastico incredibile super prodotto" | "Filtro olio Elring per BMW N47" |
| Parlare di sé | "La nostra azienda è specializzata in..." | "Trova il ricambio per la tua BMW in 30 secondi" |
| Jargon tecnico | "Coefficiente di filtraggio ISO 4548-12" | "Filtra 99% delle impurità" |
| CTA debole | "Scopri di più" | "Aggiungi al carrello — spedizione gratuita" |
| Muro di testo | Paragrafo da 200 parole | Max 3 righe per paragrafo |

## Checklist Copywriting

- [ ] Il beneficio principale è nel titolo/H1
- [ ] Ogni caratteristica ha un beneficio corrispondente
- [ ] Specifico: numeri, nomi, prove invece di aggettivi
- [ ] CTA chiara e specifica (non "Clicca qui")
- [ ] Social proof visibile vicino al CTA
- [ ] Garanzia/riduzione rischio presente
- [ ] Testo in paragrafi brevi (max 3 righe)
- [ ] Bullet point per liste di benefici
- [ ] Urgency o scarcity (se reale)
- [ ] Copy testato (A/B su headline e CTA)
