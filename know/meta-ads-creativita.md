# Meta Ads — Creatività e Copy

## Il Principio Fondamentale

Su Meta, la **creatività è il targeting**. Con iOS 14 e l'algoritmo sempre più automatizzato, non è il targeting demografico a fare la differenza — è avere l'annuncio giusto che parla al giusto segmento di utenti.

**Gli annunci migliori:**
1. Fermano lo scroll in 1-2 secondi
2. Comunicano il beneficio immediatamente
3. Hanno una CTA chiara
4. Parlano a un segmento specifico di persone

## Formati Creativi

### Immagine Singola
- **Proporzione:** 1:1 (quadrata) o 4:5 (verticale) per Feed
- **Risoluzione:** min 1080x1080px
- **Regola testo:** max 20% dell'immagine (la regola è meno rigida ora ma testo eccessivo riduce reach)

**Quando usare:** prodotti singoli con foto chiara, offerte semplici.

### Video
- **Durata:** 6-15 secondi per Reel/Stories, 15-60 secondi per Feed
- **Proporzione:** 9:16 (verticale) per Stories/Reels, 1:1 per Feed
- **Hook:** i primi 3 secondi sono cruciali — metti il punto principale subito

**Hook efficaci per video:**
```
"Stai sprecando soldi sul [problema]?"
"Questo trucco salva il motore della tua BMW"
"Errore che fa il 90% degli automobilisti"
"[Prodotto] che ho provato dopo anni di [alternativa peggiore]"
```

### Carousel
- 2-10 card (immagini o video)
- Ogni card ha titolo, testo e URL propria
- Ordine: card più performanti vengono mostrate prima automaticamente

**Usi:**
- Mostrare più prodotti correlati
- Step-by-step (come funziona, come montare)
- Prima/dopo

### Collection
- Immagine/video principale + 4 prodotti dal catalogo sotto
- Apre una "instant experience" (pagina full-screen dentro Facebook/Instagram)
- Ideale per catalogo prodotti

### Dynamic Creative
Meta testa automaticamente combinazioni di elementi:
- 5 immagini
- 5 titoli
- 3 descrizioni
→ Google crea ~75 combinazioni e trova quella migliore.

**Ideale per:** fase di test iniziale.

## Struttura Copy

### Formula AIDA per Ricambi Auto

**Attenzione:**
```
"Filtro olio BMW N47 da €9.90 — spedito domani"
"Stai cambiando l'olio BMW senza ricambista specializzato?"
"Nuovo arrivo: Elring, Mann, Corteco per BMW Serie 3"
```

**Interesse:**
```
"Ricambi OES certificati al prezzo di aftermarket.
Stessa qualità dei ricambi originali, senza pagare il margine del concessionario."
```

**Desiderio:**
```
"✓ Spedizione in 24h
✓ Reso gratuito 30 giorni
✓ Assistenza tecnica inclusa
✓ Pagamenti sicuri"
```

**Azione:**
```
"Acquista ora e risparmia sul prossimo tagliando."
```

### Copy per Diverse Temperature Audience

**Audience fredda (interessi, lookalike):**
- Non sa chi sei → devi costruire la fiducia
- Mostra prova sociale, recensioni, certificazioni
- Educare + vendere

**Audience tiepida (visitatori sito):**
- Sa chi sei → ricorda i benefici
- Metti in evidenza differenziatori (prezzo, spedizione, assistenza)
- Urgenza moderata

**Audience calda (carrello abbandonato):**
- Sa cosa vuole → elimina le obiezioni
- "Ancora disponibile", "Completa il tuo ordine"
- Eventuale piccolo incentivo (5% sconto)

## Creatività per Ricambi Auto

### Tipi di contenuto che funzionano

**1. Before/After:**
```
Prima: filtro olio sporco, motore inefficiente
Dopo: filtro pulito, consumi ridotti
```

**2. Social proof:**
```
"⭐⭐⭐⭐⭐ 'Arrivato in 24h, compatibilità perfetta con la mia BMW E90' — Marco, Milano"
```

**3. Expertise/Educazione:**
```
"Perché il filtro olio OES costa poco di più ma dura molto di più"
```

**4. Prodotto in contesto:**
```
Foto del filtro + mano meccanico che lo installa
Video "come si monta" in 60 secondi
```

**5. Offerta chiara:**
```
"Filtri BMW da €7.90 | Spedizione gratis sopra €35"
```

## Testing Creatività

### Framework A/B Testing

**Testa una variabile alla volta:**
1. Hook video (prime 3 secondi)
2. Immagine principale
3. Titolo dell'annuncio
4. CTA (bottone)

**Budget minimo per test:** €10-15/giorno per annuncio, almeno 5-7 giorni.

**Criterio vittoria:** CTR + CPA dopo 50+ impressioni significative.

### Regola del 3-2-2
Per ogni gruppo inserzioni, crea:
- 3 creatività diverse (immagine/video)
- 2 copy diversi
- 2 headline diverse

Meta ottimizza automaticamente le combinazioni migliori.

## Checklist Creatività

- [ ] Hook nei primi 2 secondi (immagine/video)
- [ ] Proporzione corretta per ogni placement (1:1, 9:16, 4:5)
- [ ] Copy con beneficio principale nel primo paragrafo
- [ ] CTA chiara e specifica
- [ ] Proofread — zero errori grammaticali
- [ ] Copy adattato alla temperatura dell'audience
- [ ] Almeno 3 creatività diverse per gruppo inserzioni
- [ ] Video sottotitolato (85% utenti guarda senza audio)
