# Content Marketing — Blog e Articoli

## Il Blog come Asset SEO e Marketing

Il blog è il canale di acquisizione più scalabile nel lungo termine. Ogni articolo è un asset che porta traffico 24/7 senza costi ricorrenti.

**Per un e-commerce di ricambi auto, il blog serve per:**
1. Catturare traffico da keyword informazionali ("come cambiare filtro olio BMW")
2. Costruire autorità e fiducia nel settore
3. Accompagnare il cliente dal problema all'acquisto
4. Contenuto per social media e newsletter

## Tipi di Articoli ad Alto Valore

### 1. Guide All'Installazione (How-To)

**Formato:** step-by-step con immagini o video
**SEO:** rank su "come cambiare [ricambio] [auto]"
**CTA:** link al prodotto nella guida

```
Titolo: "Come Cambiare il Filtro Olio BMW E90 2.0d N47 — Guida Passo Passo"
Struttura:
- Introduzione: quanto spesso va cambiato, perché è importante
- Materiali necessari: prodotti con link acquisto
- Procedura step-by-step (numerata)
- Video incorporato (YouTube tuo o embedding)
- FAQ
- Prodotti correlati
```

**Keywords target:**
- "come cambiare filtro olio BMW E90"
- "cambiare filtro olio BMW fai da te"
- "procedura cambio olio BMW N47"

### 2. Diagnosi Problemi (Troubleshooting)

**Formato:** sintomo → causa → soluzione
**SEO:** rank su "perché [problema] [auto]"

```
Titolo: "Spia olio accesa BMW E90 — Cause e Soluzioni"
Struttura:
- Introduzione (rassicura: spesso non è grave)
- Possibili cause in ordine di probabilità
- Come diagnosticare ogni causa
- Soluzione e prodotti necessari per ogni caso
- Quando portare dal meccanico (credibilità: non tutto puoi fare da solo)
```

### 3. Comparativa Prodotti

**Formato:** confronto tabellare + analisi
**SEO:** rank su "migliore [prodotto] [auto]"

```
Titolo: "Elring vs Mann vs Bosch: Quale Filtro Olio BMW Scegliere?"
Struttura:
- Introduzione: le differenze reali tra marche
- Tabella comparativa (prezzo, qualità, garanzia, compatibilità)
- Analisi dettagliata di ogni marca
- Raccomandazione finale per ogni caso d'uso
- Dove acquistare (link ai prodotti)
```

### 4. Guide Manutenzione

**Formato:** guida completa per modello/marca
**SEO:** long-tail, alta conversione

```
Titolo: "Manutenzione BMW Serie 3 E90 — Tutto quello che devi sapere"
Struttura:
- Piano manutenzione (km/tempo → intervento)
- Lista ricambi con link
- Costo stimato fai-da-te vs meccanico
- Video o link alle guide specifiche di ogni intervento
```

### 5. Guide Compatibilità

**Formato:** database ricambi per modello
**SEO:** rank su "[marca] [modello] ricambi"

```
Titolo: "Ricambi BMW Serie 3 E90 — Guida Completa Compatibilità"
Struttura:
- Modelli compresi (E90, E91, E92, E93)
- Anni produzione e motori
- Sezione per ogni categoria ricambio
- Tabella compatibilità con link prodotti
- Schema FAQ
```

## Struttura SEO-Ottimizzata di un Articolo

```
URL: /blog/come-cambiare-filtro-olio-bmw-e90/
Title: "Come Cambiare Filtro Olio BMW E90 in 10 Minuti — Guida 2024"
Meta: "Guida passo passo per cambiare filtro olio BMW Serie 3 E90.
       Materiali necessari, procedura completa, prodotti consigliati."

H1: "Come Cambiare il Filtro Olio BMW E90 — Guida Passo Passo"

Introduzione: 100-150 parole, risponde alla query in 2-3 righe

Sommario (indice):
1. Quando cambiare il filtro olio
2. Materiali necessari
3. Procedura step-by-step
4. Video tutorial
5. FAQ
6. Prodotti consigliati

H2: "Quando Cambiare il Filtro Olio BMW E90"
→ 200-300 parole

H2: "Materiali Necessari"
→ Lista con link prodotti

H2: "Procedura Completa — Step-by-Step"
→ Passi numerati con foto

H2: "Video Tutorial"
→ Video YouTube incorporato

H2: "FAQ — Domande Frequenti"
→ Schema FAQ (ottimo per featured snippet)
  Q: "Ogni quanti km si cambia il filtro olio BMW E90?"
  A: "Ogni 10.000-15.000 km, o ogni anno."

H2: "Prodotti Consigliati per BMW E90"
→ Widget prodotti WooCommerce linkati
```

## Calendario Editoriale

### Frequenza
- Sito nuovo: 2 articoli/settimana (accelera l'indicizzazione)
- Sito maturo: 1 articolo/settimana (focus su qualità)

### Template Calendario

```
Settimana 1:
- Lunedì: Guida installazione (how-to)
- Giovedì: Diagnosi problema (troubleshooting)

Settimana 2:
- Lunedì: Comparativa prodotti
- Giovedì: Guida manutenzione modello

Settimana 3:
- Lunedì: Guida compatibilità
- Giovedì: Articolo stagionale (es. "Preparare l'auto all'inverno")
```

## Ottimizzazione Articoli

### Aggiornamento Contenuti
Articoli esistenti aggiornati performano meglio dei nuovi:
- Aggiorna statistiche e anni
- Aggiungi nuove sezioni
- Aggiorna link prodotti con codici nuovi
- Cambia la data di pubblicazione a "Aggiornato: [data]"

### Link Interni
Ogni articolo deve linkare:
- Almeno 2-3 prodotti correlati
- Almeno 2 altri articoli del blog
- La categoria principale

### CTA Articolo
```
Alla fine di ogni guida installazione:
"Hai bisogno del filtro olio per la tua BMW?
Controlla la disponibilità e compra online con spedizione in 24h.
[Bottone: Trova il tuo filtro]"
```

## Distribuzione Contenuto

Ogni articolo → distribuito su:
1. Newsletter (segmento interessato a quel modello auto)
2. Facebook/Instagram (estratto + link)
3. Pinterest (infographic o step-by-step visual)
4. YouTube (versione video, se hai risorse)
5. Google Business Profile (post)

- [ ] H1 con keyword principale

- [ ] H2/H3 con keyword secondarie
- [ ] Immagini con alt text ottimizzato
