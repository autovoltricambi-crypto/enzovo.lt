# Economia per Imprese

## Costi

### Costi Fissi vs Variabili

**Costi fissi (CF)** — non cambiano al variare della produzione/vendite:
- Affitto, mutuo
- Stipendi fissi (dipendenti a tempo indeterminato)
- Ammortamenti macchinari
- Assicurazioni
- Abbonamenti software

**Costi variabili (CV)** — aumentano con la produzione/vendite:
- Materie prime e merci acquistate
- Provvigioni agenti
- Packaging e spedizioni
- Energia proporzionale alla produzione

**Costi totali (CT)** = CF + CV

**Costo unitario** = CT / unità vendute → deve essere < prezzo di vendita.

---

### Costi Diretti vs Indiretti

- **Diretti** — attribuibili a un prodotto/servizio specifico (materia prima, lavorazione)
- **Indiretti (overhead)** — condivisi tra più prodotti (affitto, amministrazione)

I costi indiretti vanno ripartiti tra i prodotti con un **criterio di allocazione** (es. ore di lavoro, % sul fatturato).

## Ricavi e Margini

### Margine di Contribuzione
```
Margine di contribuzione = Prezzo di vendita - Costi variabili unitari
```

Indica quanto ogni unità venduta contribuisce a coprire i costi fissi e generare profitto.

**Esempio:**
- Prezzo vendita: €50
- Costi variabili: €30
- Margine contribuzione: €20 per pezzo

---

### Margine Lordo (Gross Margin)
```
Margine lordo = Ricavi - Costo del venduto (COGS)
Margine lordo % = (Margine lordo / Ricavi) × 100
```

**COGS (Cost of Goods Sold)** = costo acquisto merci + costi diretti di produzione.

Settori tipici:
- E-commerce ricambi: 25–40%
- Servizi: 50–70%
- Software: 70–90%

---

### EBITDA
```
EBITDA = Ricavi - Costi operativi (esclusi ammortamenti, interessi, tasse)
```
Misura la redditività operativa pura, prima degli effetti finanziari e fiscali.
Usato per confrontare aziende diverse o valutare un'acquisizione.

---

### Utile Netto
```
Ricavi
- COGS
= Margine lordo
- Costi operativi (marketing, personale, affitti)
= EBIT (utile operativo)
- Interessi passivi
= EBT (utile prima delle tasse)
- Imposte
= Utile netto
```

---

## Break-Even Point

Il punto in cui i ricavi coprono esattamente tutti i costi (utile = 0).

```
Break-even (unità) = Costi fissi / Margine di contribuzione unitario
Break-even (€)     = Costi fissi / (Margine contribuzione % / 100)
```

**Esempio:**
- Costi fissi mensili: €10.000
- Prezzo vendita: €50, costi variabili: €30 → margine contribuzione: €20
- Break-even = 10.000 / 20 = **500 pezzi al mese**

Sotto i 500 pezzi → perdita. Sopra → profitto.

## Cash Flow (Flusso di Cassa)

**Differenza cruciale: utile ≠ cassa**

Un'azienda può avere utile positivo ma cassa negativa (es. ha venduto ma non ha ancora incassato).

### Tipi di Cash Flow
- **Cash flow operativo** — entrate e uscite dall'attività principale
- **Cash flow da investimenti** — acquisto/vendita di macchinari, immobili
- **Cash flow finanziario** — prestiti, rimborsi, aumenti di capitale

### Cash Flow Operativo
```
Utile netto
+ Ammortamenti (non sono uscite reali di cassa)
- Aumento crediti (hai venduto ma non incassato)
- Aumento scorte (hai comprato merce ma non venduto)
+ Aumento debiti fornitori (hai ricevuto merce ma non pagato)
= Cash flow operativo
```

**Regola pratica:** incassare prima possibile, pagare fornitori il più tardi possibile.

## Bilancio

### Stato Patrimoniale
Fotografia dell'azienda in un momento preciso.

**Attivo (cosa possiede):**
- Immobilizzazioni (macchinari, immobili, brevetti)
- Rimanenze (scorte di magazzino)
- Crediti verso clienti
- Liquidità (cassa, banca)

**Passivo (come ha finanziato):**
- Debiti verso fornitori
- Debiti bancari
- Debiti tributari (imposte)
- Patrimonio netto (capitale + utili accumulati)

```
Attivo = Passivo + Patrimonio netto
```

### Conto Economico
Risultato economico in un periodo (anno, trimestre).

```
Ricavi netti
- Costo del venduto
= Margine lordo
- Costi operativi
= EBIT
- Oneri finanziari
= EBT
- Imposte
= Utile netto
```

---

## Indici di Bilancio

### Redditività
| Indice | Formula | Significato |
|--------|---------|-------------|
| ROE | Utile netto / Patrimonio netto | Rendimento per i soci |
| ROI | EBIT / Capitale investito | Rendimento degli investimenti |
| ROS | EBIT / Ricavi | Margine operativo % |

### Liquidità
| Indice | Formula | Soglia |
|--------|---------|--------|
| Current ratio | Attivo corrente / Passivo corrente | > 1,5 buono |
| Quick ratio | (Attivo corrente - Scorte) / Passivo corrente | > 1 buono |

### Indebitamento
| Indice | Formula | Significato |
|--------|---------|-------------|
| Debt/Equity | Debiti / Patrimonio netto | < 1 = azienda poco indebitata |
| DSCR | Cash flow / Rata debito | > 1,25 per ottenere credito |

## Pricing

### Metodi di Determinazione del Prezzo

**Cost-plus (markup):**
```
Prezzo = Costo unitario × (1 + markup%)
```
Esempio: costo €30, markup 67% → prezzo €50

**Margine sul prezzo:**
```
Prezzo = Costo unitario / (1 - margine%)
```
Esempio: costo €30, margine 40% → prezzo = 30 / 0,6 = €50

**Competitivo:** basato sui prezzi di mercato, poi si verifica la sostenibilità.

**Value-based:** basato sul valore percepito dal cliente, non sul costo.

---

### IVA nel Pricing
In Italia l'IVA ordinaria è **22%**. I prezzi B2C includono IVA, quelli B2B di solito no.

```
Prezzo IVA inclusa = Prezzo netto × 1,22
Prezzo netto = Prezzo IVA inclusa / 1,22
```

## Indici Operativi

### Rotazione del Magazzino
```
Rotazione = COGS / Scorte medie
```
Alta rotazione → meno capitale immobilizzato in magazzino → meglio.

### DSO — Days Sales Outstanding
```
DSO = (Crediti clienti / Ricavi) × 365
```
Giorni medi per incassare dai clienti. Più basso è meglio.

### DPO — Days Payable Outstanding
```
DPO = (Debiti fornitori / COGS) × 365
```
Giorni medi prima di pagare i fornitori. Più alto è meglio (per la cassa).

---

## Leva Operativa

Misura quanto varia l'utile al variare dei ricavi.

```
Leva operativa = Margine di contribuzione / EBIT
```

- **Alta leva** (tanti costi fissi) → piccola variazione ricavi = grande variazione utile (rischio alto)
- **Bassa leva** (tanti costi variabili) → utile più stabile (rischio basso)

Aziende ad alta leva operativa: compagnie aeree, hotel, produzione industriale.
Aziende a bassa leva: rivenditori, agenti di commercio.
